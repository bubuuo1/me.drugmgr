# PWA 및 모바일

## 1. 목표

휴대폰 홈 화면에 설치하여 일반 앱처럼 사용할 수 있도록 한다.

## 2. 기술

기본 후보:

- Next.js
- React
- TypeScript
- Supabase
- Vercel

## 3. PWA

필수 고려사항:

- manifest
- 앱 아이콘
- standalone 실행
- 모바일 viewport
- 테마 색상
- 서비스 워커

## 4. 실행 경험

홈 화면 아이콘을 누르면 바로 첫 화면이 열린다.

로그인 화면은 없다.

첫 화면에서 바로:

- 메스티논 기록
- 소론도 기록
- 오늘 상태
- 기록 확인

을 사용할 수 있다.

## 5. 오프라인

가능하면 최근 데이터와 앱 기본 화면은 캐시한다.

다만 오프라인에서 생성한 투약 기록을 어떻게 서버와 동기화할지는 별도로 설계한다.

초기 버전에서는 온라인 상태를 기본으로 구현하고 오프라인 기록은 2차 기능으로 고려할 수 있다.

## 6. 모바일 브라우저

최소한 다음 환경에서 확인한다.

- Android Chrome
- iPhone Safari

## 7. 화면 방향

세로 화면을 기본으로 한다.

가로 화면은 필수 지원 대상이 아니다.

## 8. 터치

터치 영역을 충분히 크게 한다.

작은 아이콘이나 작은 텍스트 링크를 주요 조작 수단으로 사용하지 않는다.
