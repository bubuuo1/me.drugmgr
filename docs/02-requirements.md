# 기능 요구사항

## 1. 필수 기능

### 1.1 약 등록

약마다 다음 정보를 등록할 수 있다.

- 약 이름
- 단위
- 기본 복용 개수
- 복용 횟수
- 복용 예정 시간
- 활성/비활성

현재 예:

- 메스티논
- 소론도

### 1.2 투약 기록

사용자가 실제 복용한 약을 기록한다.

필수 기록:

- 약
- 복용 개수
- 실제 복용 시각

선택 기록:

- 메모

### 1.3 복용 개수 선택

기본 버튼:

- 1정
- 2정
- 3정
- 4정
- 직접 입력

약마다 필요한 선택지를 설정할 수 있도록 한다.

### 1.4 실제 복용 시각

사용자가 복용 개수를 선택하여 저장한 순간의 시간을 기본값으로 기록한다.

사용자가 필요하면 기록 확인 화면에서 시간을 수정할 수 있도록 할 수 있다.

### 1.5 메스티논

하루 여러 번 복용할 수 있다.

각 복용은 독립된 기록으로 저장한다.

예:

- 08:03 / 2정
- 12:11 / 2정
- 16:05 / 1정

### 1.6 소론도

하루 한 번 복용한다.

하루 기록을 하나의 투약 기록으로 저장한다.

## 2. 상태 기록

하루 상태를 기록한다.

기본 항목:

- 피로
- 근력
- 호흡
- 눈 증상
- 기타 메모

상태 항목은 추후 변경 가능하도록 설계한다.

## 3. 기록 확인

날짜별 기록을 확인할 수 있어야 한다.

표시:

- 날짜
- 약 이름
- 복용 시각
- 복용 개수
- 메모

날짜를 변경하여 과거 기록을 볼 수 있어야 한다.

## 4. 수정/삭제

투약 기록은 실수로 입력했을 경우 수정할 수 있어야 한다.

삭제 전에는 확인을 요청한다.

과거 기록은 설정 변경에 의해 자동으로 변경되지 않는다.

## 5. 통계

향후 추가 기능으로 고려:

- 하루 총 복용량
- 주간 복용 기록
- 월간 복용 기록
- 상태 변화 그래프

초기 버전에서는 필수 기능이 아니다.
