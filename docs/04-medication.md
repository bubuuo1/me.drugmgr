# 투약 관리 설계

## 1. 약 정보

약은 설정 데이터와 실제 투약 기록을 분리한다.

약 설정이 변경되어도 과거 기록은 변경되지 않는다.

## 2. 약 설정

예:

메스티논

- 이름: 메스티논
- 단위: 정
- 하루 복용 횟수: 여러 번
- 기본 복용량: 사용자 설정

소론도

- 이름: 소론도
- 단위: 정
- 하루 복용 횟수: 1회
- 기본 복용량: 사용자 설정

## 3. 복용 스케줄

약별로 예정 시간을 설정할 수 있다.

예:

메스티논

- 08:00
- 12:00
- 16:00
- 20:00

소론도

- 09:00

위 시간은 예시이며 실제 처방에 맞게 설정한다.

## 4. 실제 투약 기록

예:

medication_logs

2026-08-17 08:03
메스티논
2정

2026-08-17 12:11
메스티논
2정

2026-08-17 09:02
소론도
1정

## 5. 예정 시간과 실제 시간

예정 시간과 실제 복용 시간은 서로 다른 값이다.

예:

예정: 12:00
실제: 12:11

기록:

scheduled_time = 12:00
taken_at = 12:11

## 6. 추가 복용

예정되지 않은 투약도 기록할 수 있어야 한다.

예:

+ 추가 투약 기록

을 통해 약과 복용 개수를 선택한다.

## 7. 복용량

복용 개수는 정수로 저장한다.

예:

quantity = 2

단위는 medication에 저장한다.

예:

unit = "정"

## 8. 처방 변경

처방이 변경되면 새로운 설정을 적용한다.

기존 medication_logs는 변경하지 않는다.

과거 기록은 당시 실제 입력된 값 그대로 유지한다.
