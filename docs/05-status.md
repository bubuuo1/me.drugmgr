# 상태 기록

## 1. 목적

투약 기록과 함께 하루의 상태를 기록하여 나중에 변화 추이를 확인할 수 있도록 한다.

## 2. 기본 항목

초기 버전:

- 피로
- 근력
- 호흡
- 눈 증상
- 메모

## 3. 입력 방식

숫자를 직접 입력하는 것보다 선택 버튼을 우선한다.

예:

피로

- 좋음
- 보통
- 나쁨

근력

- 좋음
- 보통
- 나쁨

호흡

- 편안함
- 평소와 다름

눈 증상

- 없음
- 있음

## 4. 메모

사용자가 자유롭게 입력할 수 있다.

예:

"오후부터 피곤함"

"오늘 아침에는 평소보다 힘들었음"

## 5. 날짜

하루 하나의 상태 기록을 기본으로 한다.

날짜별로 수정할 수 있다.

## 6. 향후 확장

필요하면 다음 항목을 추가한다.

- 수면
- 식사
- 체감 피로도
- 기타 증상
- 자유로운 증상 기록

## 7. 의료적 판단

상태 점수를 근거로 앱이 의료적인 판단을 내려서는 안 된다.

앱은 기록과 시각화만 담당한다.
