## 개발 원칙

초기 버전에서는 기능을 많이 넣지 않는다.

가장 먼저 완성해야 하는 흐름:

앱 실행
→ 메스티논 선택
→ 몇 정인지 선택
→ 저장
→ 완료

이 흐름이 빠르고 편해야 한다.

그 다음 소론도와 상태 기록을 추가한다.
