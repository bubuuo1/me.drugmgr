# 디자인 시스템 - 모바일 UI 및 접근성

## 0. 디자인 베이스

이 문서는 앞으로의 모든 화면 디자인의 기준(base)이 된다.

시각적 언어의 뼈대는 Airbnb 디자인 시스템에서 가져온다.

- 따뜻하고 친절한 형태 언어
- 깨끗한 흰 캔버스 + 단 하나의 브랜드 강조색(Rausch #ff385c)
- 부드러운 라운딩(모서리가 모난 곳이 없음)
- 얇고 차분한 타이포 가중치 + 넉넉한 여백
- 플랫한 표면 + 단일 섀도우 티어

Airbnb는 사진으로 시각적 무게를 주지만, 이 앱은 사진이 없다.

따라서 시각적 무게를 **큰 텍스트 라벨과 넓은 터치 영역**으로 대체한다.

"빠르게 누르는 것"이 최우선이며, 접근성을 절대 훼손하지 않는다.

참고: `DESIGN-airbnb.md` — Airbnb 디자인 분석 원본. 위 색상/타이포/라운딩/간격 토큰은 모두 해당 문서에서 유래했다.

## 1. 기본 원칙

이 앱은 일반적인 관리용 대시보드가 아니다.

사용자가 하루에도 여러 번 열어서 빠르게 투약을 기록하는 앱이다.

따라서 "보여주는 정보"보다 "빠르게 누르는 것"을 우선한다.

디자인 원칙:

- 모바일 우선, 세로 화면 기준
- 화면당 핵심 동작 1~2개만 유지
- 정보는 화면 마지막까지 지연 표시(불필요한 정보 최소화)
- 색상만으로 상태를 구분하지 않는다(항상 텍스트와 함께)
- 사용자가 휴대폰 글자 크기를 확대해도 레이아웃이 깨지지 않는다

## 2. 디자인 토큰

토큰은 구현 시 CSS 변수로 정의하고 모든 컴포넌트가 이를 참조한다.

하드코딩된 색상/크기는 사용하지 않는다.

### 2.1 색상 Colors

주소: `docs/03-ui.md` · 원본: `DESIGN-airbnb.md`

| 토큰 | 값 | 용도 |
|---|---|---|
| `primary` | `#ff385c` (Rausch) | 모든 주요 CTA. 이 앱에서 유일한 강조색 |
| `primary-active` | `#e00b41` | 버튼 누름 상태(press) |
| `primary-disabled` | `#ffd1da` | 비활성 CTA |
| `ink` | `#222222` | 제목·본문의 기본 텍스트(순수 검정 아님) |
| `body` | `#3f3f3f` | 보조 본문 텍스트 |
| `muted` | `#6a6a6a` | 보조 라벨, 비활성 탭, 날짜 등 |
| `muted-soft` | `#929292` | 비활성 링크(아껴서 사용) |
| `canvas` | `#ffffff` | 기본 배경 |
| `surface-soft` | `#f7f7f7` | 비활성 필드, 하단 동작 바, 탭 배경 |
| `surface-strong` | `#f2f2f2` | 아이콘 버튼 원형 표면 |
| `hairline` | `#dddddd` | 1px 경계선(카드, 구분선) |
| `hairline-soft` | `#ebebeb` | 더 연한 구분선(긴 본문용) |
| `on-primary` | `#ffffff` | 강조색 위의 텍스트 |
| `error` | `#c13515` | 오류 텍스트 |

시맨틱 보조 색상 — Airbnb 토큰에 없어 이 앱용으로 추가:

| 토큰 | 값 | 용도 |
|---|---|---|
| `success` | `#007a33` | "복용 완료" 상태. 반드시 텍스트와 함께 사용 |
| `warning` | `#b32505` | "미기록/누락" 상태 표시용. 반드시 텍스트와 함께 사용 |

색상 규칙:

- 강조색은 화면당 1~2곳으로 절제한다(흰 캔버스 + ink가 기본).
- 복용 완료 = 녹색 + "복용 완료" 텍스트
- 누락 = 경고색 + "미기록" 텍스트
- 색상만으로 상태를 구분하지 않는다.

대비 기준:

- 보통 텍스트: WCAG AA 4.5:1 이상
- 큰 텍스트(20px 이상): WCAG AA 3:1 이상
- `Rausch(#ff385c) + 흰 텍스트`는 약 3.5:1이므로 **주요 CTA 라벨은 반드시 큰 텍스트(20px/700)** 로 사용해 기준을 충족한다.

### 2.2 타이포그래피 Typography

폰트 패밀리(우선순위):

```
'Airbnb Cereal VF', Circular, -apple-system, system-ui, Roboto, 'Helvetica Neue', sans-serif
```

- Airbnb Cereal VF / Circular 미사용 시 대체 폰트는 **Inter**.
- 이 앱은 접근성을 위해 Airbnb 기준보다 한 단계 큰 본문 크기를 사용한다.
- 폰트 크기는 `rem` 등 유동 단위로 지정해 시스템 글자 확대에 대응한다.

| 토큰 | 크기 | 가중치 | 용도 |
|---|---|---|---|
| `display` | 24px | 700 | 화면 제목(약 이름 등) |
| `title` | 20px | 700 | 뷰 제목("몇 정 드셨나요?", "오늘 총 복용량") |
| `button-xl` | 20px | 700 | 주요 CTA·첫 화면 버튼 라벨 |
| `button-lg` | 20px | 600 | 복용 개수·상태 선택 버튼 라벨 |
| `button-md` | 18px | 600 | 보조 버튼 라벨 |
| `body` | 18px | 400 | 기본 본문(접근성 확대) |
| `body-sm` | 16px | 400 | 날짜·시간·메모 등 세부 정보 |
| `caption` | 14px | 500 | 필드 라벨·보조 텍스트 |

### 2.3 라운딩 Rounded

| 토큰 | 값 |
|---|---|
| `sm` | 8px |
| `md` | 14px |
| `lg` | 20px |
| `xl` | 32px |
| `full` | 9999px |

적용:

- 주요 버튼(복용·상태 선택): `full`(알약 형태의 pill)
- 카드: `md`~`lg`
- 입력 필드: `sm`
- 작은 배지는 `full`

모서리가 모난(None) 요소는 기본적으로 사용하지 않는다.

### 2.4 간격 Spacing

- 4px 기반(8px base 유닛).
- 첫 화면 버튼 사이: `lg`(24px) 이상의 넉넉한 간격.
- 화면 안쪽 여백: `base`(16px) ~ `lg`(24px).
- 섹션 간 여백: `xxl`(48px).
- 빡빡함 대신 여백으로 "누르기 쉽게" 만든다.

### 2.5 고도 Elevation

- Airbnb 방식: **단일 섀도우 티어 1개**만 사용한다.

```
box-shadow: rgba(0,0,0,0.02) 0 0 0 1px,
            rgba(0,0,0,0.04) 0 2px 6px 0,
            rgba(0,0,0,0.1) 0 4px 8px 0;
```

- 기본적으로 플랫(평면)이다.
- 위 그림자는 드롭다운·플로팅 카드 등 떠 있어야 하는 요소에만 적용한다.
- 깊이감은 그림자가 아니라 표면의 흰색 대비와 라운딩으로 만든다.

## 3. 컴포넌트

### 3.1 첫 화면 메인 액션 버튼

`home-action-primary` — Rausch 채움, 흰 텍스트, `full` pill.

- 높이: 72px 이상
- `button-xl`(20px/700) 라벨
- 넓은 터치 영역, 라벨은 텍스트로 명확히 표시

`home-action-secondary` — 흰 표면, ink 텍스트, 2px ink 아웃라인, `full` pill.

- 높이: 72px 이상
- 위와 동일한 라벨 규칙

배치(권장):

- 메스티논 기록 / 소론도 기록 → `home-action-primary`
- 오늘 상태 / 기록 확인 → `home-action-secondary`

누르면 즉시 해당 기록 화면으로 이동한다.

### 3.2 복용 개수 선택 버튼

`quantity-button` — 흰 표면, 1px `hairline` 아웃라인, `full` pill.

- 높이: 64px 이상
- `button-lg`(20px/600) 라벨 ("1정", "2정", "3정" ...)

`quantity-button-selected` — Rausch 채움, 흰 텍스트(큰 텍스트 대비 충족).

- 선택 즉시 저장으로 이어진다.

`quantity-input` — "직접 입력"용. `text-input`과 동일 규격(3.6).

### 3.3 상태 선택 버튼

`status-option` — 흰 표면, 1px `hairline`, `full` pill, 56px 이상 높이.

- 라벨: "좋음" / "보통" / "나쁨" 등 텍스트 그대로 표시
- 선택됨: Rausch 채움 + 흰 텍스트
- 색상만으로 구분하지 않는다(위 약명 라벨=텍스트).

### 3.4 저장·완료

`button-primary` — Airbnb 기준: Rausch 채움, 14×24px padding, 높이 56px 이상, `sm` 라운딩, `button-md`(18px/600). 저장 등 최종 CTA.

`save-confirmation` — 저장 완료 알림.

- 예: "메스티논 2정 / 16:05 기록 완료"
- `surface-soft` 배경 + 체크 아이콘 + `button-md` 텍스트
- 확인 후 첫 화면으로 복귀

`button-tertiary-text` — 표면 없이 ink 텍스트만. 수정/삭제 링크용. 최소 터치 높이 48px 이상 확보.

### 3.5 기록 확인

`record-section-title` — `title`(20px/700)의 약 이름. 아래 `hairline` 구분선.

`record-row` — `body-sm`(16px/400). "08:03  2정" 형태로 시각과 개수를 좌우 배치.

- 시각: `ink`
- 개수: `body`(또는 강조 시 `ink`)

`daily-total-card` — 흰 표면, 1px `hairline` 테두리, `md` 라운딩.

- "오늘 총 복용량: 메스티논 5정 / 소론도 1정"
- `title`(20px/700) 제목 + `body` 본문

`date-navigator` — 날짜 이동(이전/다음/오늘). `text` 링크 또는 `icon-button-outline`(상태 `surface-strong` 원형 아이콘 버튼, 높이 40~48px).

### 3.6 입력 필드

`text-input` — Airbnb 기준.

- 흰 표면, 1px `hairline` 아웃라인, `sm` 라운딩, 높이 56px
- 라벨: `caption`(14px/500) muted, 필드 위에 적층
- 포커스 시: 테두리 2px `ink`로 변경(글로우 없음)

### 3.7 날짜 선택

`date-picker-day` — 44px 이상 원형 셀(`full`).

- 기본: 투명 배경, ink 숫자
- 선택됨: ink 채움 + 흰 텍스트(Airbnb 방식, 높은 대비)

### 3.8 소형 배지

`badge` — 흰 pill(`surface-soft` 또는 `canvas`), 11px/600. "복용 완료" 등 상태 라벨에 텍스트와 함께 사용.

## 4. 첫 화면

큰 버튼 4개를 기본으로 한다. 불필요한 정보는 표시하지 않는다.

- 메스티논 기록
- 소론도 기록
- 오늘 상태
- 기록 확인

배치 규칙: 버튼 순서는 위와 같다. 각 버튼은 `home-action` 규격(72px+)을 따른다.

## 5. 메스티논 기록 화면

소론도도 동일한 화면 구조를 사용한다(약 이름만 변경).

구성:

- 화면 상단: 약 이름(`display` 24px/700)
- 질문: "몇 정 드셨나요?"(`title` 20px/700)
- 복용 개수 버튼 그리드: [1정] [2정] [3정] [4정] [직접 입력]
- 사용자가 개수를 선택하면 즉시 저장한다.
- 저장 후: "메스티논 2정 / 16:05 기록 완료"(`save-confirmation`) 표시 → 첫 화면 복귀

## 6. 상태 기록 화면

투약 기록과 분리된 화면. 큰 선택 버튼 사용.

구성:

- 피로: [좋음] [보통] [나쁨]
- 근력: [좋음] [보통] [나쁨]
- 호흡: [편안함] [평소와 다름]
- 눈 증상: [없음] [있음]
- 기타 메모: `text-input`
- 저장: `button-primary`

각 그룹은 `status-option` 규격을 따른다.

## 7. 기록 확인 화면

하루 기록을 날짜별로 보여준다.

구성:

- 날짜 헤더 + `date-navigator`(이전/다음/오늘)
- 약별 섹션: `record-section-title` + `record-row` 목록

```
8월 17일

메스티논
08:03  2정
12:11  2정
16:05  1정

소론도
09:02  1정

오늘 총 복용량
메스티논 5정
소론도 1정
```

- 하단: `daily-total-card`
- 개별 기록: 수정(`button-tertiary-text`), 삭제(삭제 전 확인 요청)
- 시간 수정 허용(실수 입력 대응)

## 8. 접근성(핵심)

- 터치 영역: 주요 버튼 64~72px, 최소 48px 이상.
- 버튼 간 충분한 간격(24px 이상).
- 대비: WCAG AA 이상 유지(`primary` CTA는 라벨을 큰 텍스트로).
- 색상만으로 상태를 구분하지 않는다(항상 텍스트와 함께).
- 글자 크기: `body` 18px 기준, 시스템 확대에도 레이아웃 안정.
- 아이콘만 사용하지 않는다(라벨 텍스트 필수).
- 화면 낭독기: 버튼/상태의 접근 가능 이름 제공.
- 색각 이상 고려: 강조색 대비·라벨 병행.

## 9. 다크 모드(향후 지원)

- 색상은 모두 토큰으로만 사용해서 라이트/다크 전환 가능하게 설계한다.
- 라이트/다크 모두 동일한 대비 기준(AA 이상)을 유지한다.
- 구현 전 단계에서는 다크 팔레트를 확정하지 않는다.

## 10. 구현 지침

- 2장의 모든 토큰을 CSS 변수(또는 디자인 토큰 파일)로 정의한다.
- 컴포넌트는 하드코딩 없이 토큰만 참조한다.
- 첫 화면 화면 구성 변경 시 토큰 규칙은 유지한다.
