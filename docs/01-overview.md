# 투약 관리 앱 - 프로젝트 개요

## 1. 목적

아내가 휴대폰에서 간편하게 약 복용과 건강 상태를 기록할 수 있는 개인용 투약 관리 앱을 만든다.

핵심 목적은 "약을 먹었다는 사실을 빠르고 정확하게 기록하는 것"이다.

## 2. 기본 방향

- 로그인 기능 없음
- 사용자 1명만 사용
- 모바일 우선
- 휴대폰에서 앱처럼 사용
- PWA 형태를 우선 고려
- Vercel 배포
- Supabase 데이터 저장
- 인터넷이 일시적으로 없어도 최근 화면과 기록 기능이 최대한 동작하도록 고려
- 화면 접근성을 최우선으로 한다.

## 3. 핵심 약

현재 관리 대상:

- 메스티논
  - 하루 여러 번 복용
  - 복용할 때마다 실제 복용 개수를 기록
- 소론도
  - 하루 한 번 복용
  - 실제 복용 개수를 기록

약의 용량이나 복용 일정은 앱이 임의로 판단하거나 변경하지 않는다.

사용자가 설정한 복용 계획을 기준으로 기록만 관리한다.

## 4. 가장 중요한 UX

앱을 자주 여는 이유는 투약 기록이다.

따라서 첫 화면은 복잡한 일정표가 아니라 큰 버튼 몇 개만 표시한다.

예:

- 메스티논 기록
- 소론도 기록
- 오늘 상태
- 기록 확인

약을 선택하면 복용한 개수를 선택하고 바로 저장한다.

## 5. 기본 기록 흐름

메스티논:

1. 메스티논 기록 선택
2. 복용 개수 선택
3. 현재 시각 자동 기록
4. 저장 완료
5. 첫 화면으로 복귀

소론도도 동일하다.

## 6. 상세 기록

첫 화면에서는 단순하게 유지한다.

상세 투약 내역은 "기록 확인" 화면에서 제공한다.

예:

- 08:03 메스티논 2정
- 12:11 메스티논 2정
- 09:02 소론도 1정

## 7. 안전 원칙

이 앱은 의료적 판단을 하는 프로그램이 아니다.

- 복용량을 자동으로 변경하지 않는다.
- 처방 변경을 권고하지 않는다.
- 누락된 약을 임의로 복용하도록 안내하지 않는다.
- 기록과 처방 설정을 분리한다.
- 과거 투약 기록은 당시 입력된 값 그대로 보존한다.
